# Receipt fonts

Self-hosted Noto Sans and Noto Sans Arabic variable TrueType fonts, obtained on 12 October 2026 from the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/notosans
- https://github.com/google/fonts/tree/main/ofl/notosansarabic

Both fonts are distributed under the SIL Open Font License 1.1. Their upstream license texts are included alongside the font files. Fonts are loaded locally, then embedded as data URLs inside the browser SVG capture so Arabic shaping and Turkish/Cyrillic glyphs survive rasterization. The generated PDF is a raster page; the staff/public web interface remains HTML.
