GOOGLE APPS SCRIPT (E-TABLO) GUNCELLEME KODLARI
-------------------------------------------------

Bu dosya, Vercel uzerindeki "Isaretle" ve "Isareti Kaldir" butonlarinin e-tablolarla tam uyumlu ve senkronize calismasi icin Google Apps Script projenize (Google Sheets -> Uzantilar -> Apps Script) yarin eklemeniz gereken iki kod blogunu icermektedir.

Sutun Yapisi Bilgisi:
- A Sutunu (Index 0): Isim
- B Sutunu (Index 1): No
- C Sutunu (Index 2): Alinma Tarih ve Saati (Isaret)

-------------------------------------------------
1. KOD BLOGU: ARAMA SONUCLARINA "ISARETLI" BILGISINI EKLEME
-------------------------------------------------
Nereye eklenecek: Arama yapip sonuclari `sonuclar.push(...)` ile diziye eklediginiz dongunun icine eklenecek.
Ne ise yariyor: Farkli bir bilgisayardan arama yapildiginda da kisinin zaten isaretlenmis (alinmis) olup olmadigini arayuzun bilmesini saglar (butonlari yesil yapar).

Eklenecek Kod:

// C sutununda (index 2) alinma tarihi ve saati varsa isaretlenmis demektir.
var isaretliMi = (row[2] !== "" && row[2] !== null && row[2] !== undefined); 

sonuclar.push({
   sayfa: sayfaAdi, // Sizin arama dongunuzdeki mevcut sekme adi degiskeni (sayfa veya sayfaAdi)
   isim: row[0],    // A Sutunu: Isim
   no: row[1],      // B Sutunu: No
   isaretli: isaretliMi // <-- Yeni eklenen kontrol
});

-------------------------------------------------
2. KOD BLOGU: "ISARETI KALDIR" (UNMARK) ISLEMINI TANIMLAMA
-------------------------------------------------
Nereye eklenecek: doPost veya doGet fonksiyonunuzda action'lari (ornek: action === 'update') kontrol ettiginiz if/else veya switch/case yapisina eklenecek.
Ne ise yariyor: Arayuzdeki kirmizi "Kaldir" butonuna basildiginda, e-tablodaki ilgili kisiyi bulup C sutunundaki tarihi/saati siler.

Eklenecek Kod:

if (action === "unmark") {
    var sayfa = e.parameter.sayfa; // Sekme adi (Orn: 20.07.2026)
    var isim = e.parameter.isim;   // Kisi adi
    var no = e.parameter.no;       // Numarasi
    
    // Gelen sayfa (sekme) adiyla o sayfayi ac
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(sayfa);
    
    if (sheet) {
        var data = sheet.getDataRange().getValues();
        
        // Satirlari tara (0. satir baslik oldugu icin 1'den baslatiyoruz)
        for (var i = 1; i < data.length; i++) {
            
            // A Sutunu (data[i][0]) Isimle, B Sutunu (data[i][1]) No ile eslesiyor mu?
            if (data[i][0] == isim && data[i][1] == no) {
                
                // Eslesti! C sutunundaki (3. sutun) tarih ve saati sil:
                sheet.getRange(i + 1, 3).clearContent(); 
                
                // Arayuze basarili mesaji gonder
                return ContentService.createTextOutput(JSON.stringify({ 
                    success: true, 
                    message: "Isaret kaldirildi" 
                })).setMimeType(ContentService.MimeType.JSON);
            }
        }
    }
    
    // Bulunamazsa hata gonder
    return ContentService.createTextOutput(JSON.stringify({ 
        success: false, 
        error: "Kayit bulunamadi" 
    })).setMimeType(ContentService.MimeType.JSON);
}
