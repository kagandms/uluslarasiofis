Help and print status

Files and limits

PDF, JPG and PNG files are supported. Each file can be up to 10 MB; a job can include up to 20 pages.

PDF pages and settings

Use a range such as 1-5, 3,7 to print selected pages. Color and other options appear only when the printer supports them.

What job statuses mean

Queued means waiting to print. Sent means the Print Agent handed the job to the computer's printer queue; it does not confirm physical output. If a result is uncertain, do not send the same file again.
